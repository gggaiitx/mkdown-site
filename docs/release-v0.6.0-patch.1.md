# 码克 v0.6.0-patch.1

v0.6.0 的补丁版，全部集中在「就地办完事」这一条线上：右键菜单打通三引擎的三种形态（阅读态与分栏预览窗格也接得上），内容版式加了第四档「自适应」，字号改成 0.5px 一档并补上键位，大纲的当前章节一眼认得出。

## 右键菜单打通到每一个窗格

- **全屏项跟着状态走**：已经在全屏里时，菜单首项自动变成「退出全屏」（图标同步），F11 与功能栏按钮仍是同一套状态，三引擎三形态一致。
- **阅读态接管右键**：Markdown 的阅读栏与富文本 `.mh` 的只读栏此前不接管（点了没反馈的项目当时没做实）。现在这两处都出菜单，条目集换成只读那一套：搜索 / 复制全文 / 内容版式▸ / 回编辑态（Markdown 另给分栏）。
- **分栏的预览窗格同步接管**：判据从"是不是阅读态"改成"这块窗格的内容是不是可编辑源码"——分栏右侧的预览栏同样是只读窗格，走同一套条目；「内容版式」在分栏档不挂版式类，因此不给，源码语义的表格·标题·格式同理隐去。
- **三引擎编辑态整合**：动作区不再各写一条分支，统一成一条流程按引擎与形态裁剪，Markdown 与 `.mh` 的编辑态补上了此前只有代码页才有的「搜索」与「复制全文」。取舍规则：菜单只补这一层此刻别处拿不到的入口。
- **只读态的专注模式做实**：阅读态没有编辑光标可依，「当前块」改按指针落点判定，与编辑态共用同一套压淡样式；从右键菜单开开关即刻有反馈。
- 边界照旧：链接与图片上不接管，系统菜单的「复制链接地址 / 图片另存为」应用菜单给不出等价项。
- 文案归一：菜单里的「行号」改为「显示行号」，与设置项同名。

## 内容版式加了第四档

- **自适应（随窗口铺满）**：不再给正文列设宽度上限，编辑与阅读两态都跟着窗口铺满，配合 F11 全屏阅读正好。原有窄 / 中 / 宽三档不变，默认仍是「中」。
- 右键菜单与设置面板同时可选，两处同一字段、双向同步。

## 字号改为一档 0.5px，并补上键位

- **四个入口同档同向**：顶栏 ± 按钮、`Ctrl+滚轮`、新增的 `Ctrl+=` / `Ctrl+-`（`Ctrl+0` 回默认 15px）、设置里的字号滑块，全部以 0.5px 为一档，范围仍是 12~24px。
- 半档值会折回 0.5 网格，老配置里遗留的非半档值不会漂在网格之外。附带好处：导出 Word 按半磅取整，0.5px 一档正好落进整数半磅。
- 设置存储的字号类型由整数改为浮点，否则 15.5 这类值存不进去。

## 大纲的当前章节一眼认得出

- **传统面板**：选中条此前与悬停条是同一个底色，静止时认不出来；现在给一档实打实的淡墨底（亮色与暗色分别取档），悬停态退回中性灰。
- **清新浮标**：收起态只靠「横线加长 + 满墨」认当前条（不给装饰性底色），掠过展开成窗体后才叠上与传统面板同档的淡墨底。
- **修：浮标掠开时位置不跟随**。展开一行内距从 1px 撑到 5px，整列高度约翻倍，按收起态算好的滚动位置会把当前条顶出视野；现在展开时重新校正一次，过渡结束再补一次。
