# 码克 v0.5.9-beta.2

Beta 版，两项内核层改动：三个编辑内核改为常驻（切标签不再销毁重建），`.mh` 富文本编辑页补上编辑区右键菜单。用于实测确认，不进正式版通道——官网与 README 的下载入口仍指向 v0.5.9。

## 内核常驻：切档不再丢撤销栈、滚动位置与已渲染内容

- **症状**：Markdown 文档与 `.mh` 富文本、代码/文本标签之间来回切换时，切走再切回来编辑器是全新的——刚才的撤销历史没了、视口回到文档顶部、Mermaid 与公式要重画一遍；切到 `.mh` 还常有数百毫秒的卡顿。
- **原因**：Markdown 内核随标签类型条件挂载，标签一换就整个销毁重建；富文本内核虽已常驻，但另两个内核仍是随用随建。
- **修复**：三个内核统一改为「首次用到才挂载，此后常驻，只切显隐」。配套补了四件必要的事：隐藏期间不吃外部内容（避免切回时被判定为外部变更而整篇重建）、隐藏期间冒出的事件一律丢弃（防止把 A 文档的正文写进 B 标签）、按标签保存并恢复滚动位置（元素隐藏时浏览器会丢掉滚动位置）、以及把查找高亮的派发目标从「全局当前编辑器」改为「发起请求的那个编辑器」——两个内核同时存活后，旧的全局指针会被后挂载者抢走，表现为高亮画在看不见的那一份上。
- **顺带修掉**：预览类标签（Word / Excel / 图片 / PDF）下查找与大纲跳转不再可能落到隐藏的编辑器上；Markdown 内核的打印与导出宿主在切到别的内核时退出打印范围（常驻后两份宿主会同时存在，否则打印 `.mh` 会先叠一篇 Markdown 预览）；行号列的几何量测在隐藏期不再被写成 0，切回来不闪。
- **影响面**：标签切换、多内核并存、查找高亮、打印与导出。内容与磁盘格式无变化。
- **已知边界**：同一内核内部互切（Markdown ↔ Markdown、代码 ↔ 代码）仍共用一条撤销历史，撤销有机会把另一篇的文本带回来；这是常驻前就有的行为，按文档隔离撤销需要另做一层，留待后续。

## `.mh` 编辑页右键菜单：刷新 + 专注模式

- **内容**：在 `.mh` 正文区右键，弹出与 Markdown 编辑区同款的菜单，含「刷新」与「专注模式」两项——刷新走标签栏那条现成链路（未保存改动先弹「重新加载 / 保留我的改动」），专注模式是视图级开关，状态落设置文件、跨文档保持。
- **口径**：只给这两项。行号是代码窗格的概念，表格 / 标题 / 加粗等是 Markdown 源码语义，对富文本无意义，故不出现；工具条与弹层里的右键不接管，留给系统菜单；阅读态不接管（专注模式在只读态不生效）。
- **注意**：未保存草稿没有磁盘来源，此时菜单只出「专注模式」一项，保存后「刷新」才会出现。
