# 码克 v0.7.4

这一版两条线：一是一次全量代码审查后的整修——文件树终于能把文件拖来拖去了，GBK / UTF-16 文档不再只能另存为，界面出错也不再是一块白板；二是书桌右下角养了一只猫。

## 文件树 · 整理文档库不用再切到资源管理器

- **拖拽移动**：按住文件或目录行，拖到目标目录松手即移动；在同一目录内上下拖则是换序。
- 拖拽是**自己用指针事件画的**，不是浏览器原生拖放。Tauri 在 Windows 上接管了系统 OLE 拖放，HTML5 的 drag 事件根本到不了前端；关掉它又会失去「从资源管理器拖文件进窗口打开」。两害相权，只能自己实现——所以那个能力照旧好使。
- 落点只认目录行与树的空白区（= 工作区根）；自身、自身子目录、**原父目录**都不给落点（原父目录本来就不是移动，高亮后松手没反应会让人以为操作丢了）。
- 位移小于 4px 仍算点击：点文件名照常打开、点目录照常展开折叠。
- **跨盘移动**先完整复制再删源，复制中途失败只清半成品，源文件原样保留；目标已有同名条目一律拒绝覆盖（用 `create_new` 一次完成判重与创建，`fs::copy` 会覆盖窗口期内新冒出来的同名文件）。
- 贴近树的上下缘会自动滚动，长树也能拖到屏外目录；指针落在滚动条滑块上不算落点。
- **行末可显示修改时间与大小**（出厂关，设置 → 操作 → 资源管理器）。打开后是表格布局，三列右缘对齐，装不下就横向滚动；两列全关则回到原来的块布局，名字按容器宽自适应。缩进同时从 16px 收到 12px，多出来的宽度留给文件名。
- **六种排序**：名称 / 修改时间 / 大小，各两向。目录恒在前；缺值的目录退化为名称序，不会「点了大小排序目录乱跳」。排序直接重排树本身，所以方向键导航、过滤结果、选中定位三者顺序始终一致。
- 名称比较里数字按数值走（`img2` 在 `img10` 前面），并且刻意不用 `Intl.Collator`——ICU 把汉字排在拉丁字母之前，而后端建树用的是码点序，两套规则混用会让「名称 A→Z」一开就跟刚打开工作区时的顺序不一样。
- **侧栏宽度记忆**：工作台侧栏与书桌左栏各记一份（书桌要留空间给卡片，两处宽度互不干扰），共用「记住侧栏宽度」一个开关。窗口变窄时只夹渲染宽度，不回写你拖出来的目标值，拉宽回来能自己弹回去。
- 移动 / 重命名后，标签的路径与目录展开态**先跟随再刷新**；刷新失败只提示「视图可能过期」，不会把已经成功的操作报成失败。

## 保真度 · GBK / UTF-16 文档能就地保存了

- 保存按**原编码回写**，UTF-16 两档保住 BOM（无 BOM 的 UTF-16 下次打开会被当未知编码，整篇乱码）。
- 三道闸，缺一不可：
  - 编码无法表示的字符（GBK 里写 emoji）**明确报错**，绝不静默替换成 `?`——静默替换会悄悄改坏文档，用户无从发现；
  - 写盘前做一次 encode → decode 往返校验。编码是猜出来的，把 GBK 认成 windows-1252 时往返必然对不上，宁可拒绝保存也不能写坏原文件；
  - 读取时就已经出现乱码的文档（原文里已有 U+FFFD，字节不可还原）禁止就地保存，后端直接拒绝并引导另存为 UTF-8。
- 保存失败时提示会露出后端的具体原因（哪种编码表示不了哪些字符），不再只有一句笼统的「保存失败」。

## 稳定性 · 界面出错不再停在白板

- Vue 运行时错误、`window.onerror`、未处理的 Promise rejection 统一收口，写入 `%APPDATA%\com.feizong.mkdown\logs\renderer.log`，带上时间戳、栈、当前标签路径。
- 日志三条纪律：单条字段 8KB 截断（错误里夹带整段 HTML 时不会一条顶满额度）、正文压成单行（错误消息里的换行不会伪造出「另一条记录」）、主目录替换成 `~`（贴进 issue 时不带用户名）。1MB 轮转一代，长期运行不会写满磁盘。
- 同类错误 60 秒内只记一次，去重表上限 200 条（渲染循环里的异常每秒能抛几十次，不去重会把有用的首条轮转掉）。
- `ResizeObserver loop`、`Script error.`、`AbortError` 三类不记为故障——前两类是良性告警，后者是主动取消读盘，报成「界面出错」既误导又刷日志。
- 首次出错给一条提示，**F5 直接重载**。重载前会把待落盘的草稿刷进会话快照，不会丢编辑。

## 启动与打开

- 双击关联文件不再先绕欢迎页一圈：把「有没有待打开的启动文件」的判定提到最前，从首帧就等它回来。无启动文件时判定只用几毫秒，正常启动几乎无感。
- 打开较大的文档时，中心区显示「正在打开「xxx」…」，不再是一片空白。
- 启动文件的编辑器内核提前并行拉起（只按扩展名猜，猜错最多白拉一个 chunk）。
- 从书桌「继续写作」或整张纸卡进去，无论默认视图是什么都落编辑态；「预览」则强制阅读态——标签本体的模式也一起改，否则会被上一个标签的阅读态盖掉。

## 图片预览

- 拖拽平移从「搬滚动条」改成 `transform` 位移：放大后不再冒出滚动条，缩小到比画布还小也能拖（左右、上下贴齐），两档共用同一条夹取口径。
- 缩放、切图、面板尺寸变化后，位移按最新尺寸重新夹一遍，不会飘出边界。

## 预览主题

- 编辑器右键新增「预览主题」飞窗，7 套主题直接换，改完当帧生效。
- 只给 Markdown 的预览窗格：`.mh` 的正文走 wangEditor，主题对它不生效；编辑态没有预览 DOM，改了看不到反馈——两处都不给。
- 主题列表抽成唯一真相源，设置面板与右键菜单共用一份，以后加主题只改一处。

## 标签栏

- 拖拽换序同样改成指针自绘：越过 4px 阈值才算拖（普通点击不受影响），拖到边缘自动滚动，松手后吞掉紧随的 click——不会顺手把被拖的标签激活。

## 新增 · 码猫

书桌右下角、底部状态栏右端常驻一只小猫，固定 52px，屁股贴着状态栏上沿，与窗口宽度无关。

- 四张表情原图交叉淡化，切换时头和脚都不会跳（四张已归一化到同一画布：头顶到脚底等高、底边对齐、水平居中）。
  - 平时睁眼坐着，每 5.2 秒眨一次眼
  - 指针移上来 → 举爪打招呼
  - 点一下 → 眯眼笑并蹦一下
  - 半分钟没碰键鼠 → 打哈欠，呼吸放慢到 7.2 秒
- 点击有 38 条随机台词：猫的视角、吐槽文档，不连着两次出同一句。
- 双击直接打开「继续写作」。
- 定时提醒：每小时 :01 和 :31 提醒起身接水（5 条随机），12:00 提醒干饭，17:30 提醒下班。饭点与紧随其后的 :01 只弹一条。
- 设置 → 操作 → 码猫 可整体关掉。

细节：微动（呼吸 + 极轻侧倾）做在外层容器上，与表情切换互不干扰，换脸时身子不会跟着抖；眨眼是单独一层覆盖，可独立节流，不必把整段呼吸循环压慢；状态栏右侧的引擎名按猫的宽度让位；提醒按钟点排程而不是轮询，系统休眠唤醒回来若已错过两分钟，那一轮作废不补发。

## 已知限制

- 猫只在书桌页出现，进编辑器后不跟随。
- 提醒在窗口最小化或不在书桌页时跳过，不补发，等下个整点或半点。
- 搜索仍只按扩展名识别文本，无扩展名的 `Makefile` / `LICENSE` 搜不到（与「编辑器能打开无扩展名文本」尚不一致）。
- 粘贴图落盘的 `assets/` 目录没有「清理未引用资源」入口，长期使用会积累孤儿图片。
- 标签栏拖拽与文件树拖拽都依赖指针事件，触控板手感尚未做真机调优。
- macOS 产物仍未做代码签名与公证，首次打开需右键「打开」绕过 Gatekeeper。
