# 码克 v0.5.9

本版聚焦「看得见、改得准」：Markdown 编辑窗格补上可选行号，查找面板补上全文替换，专注模式覆盖到三个编辑内核，并清掉一批来自 v0.5.8 代码审查的稳定性问题。

## 可选行号（Markdown 编辑窗格）

- **两处开关**：设置「编辑器」页与编辑区右键菜单均可切换（右键项带当前状态勾选标记），开关持久化保存。切换只切一个 class，不重配编辑器扩展、不补发事务，因此不打断输入与撤销栈。
- **一条稳定的竖线**：数字贴窗格左边界，字号钉死 12.5px 不随全局字号缩放，等宽数字不随位数抖动，标题行与正文行的数字左右、上下都在同一列上。
- **不参与选区着色**：行号列的左留白挂在行自身而不是内容容器上，选区底色按字形坐标绘制，不会探进行号列。
- **零依赖实现**：不引入 gutter 扩展，改为给可视区每一行挂行号属性、由样式画出数字，因此开启/关闭都不会让编辑器重建。
- 已知代价：关闭「自动换行」后横向滚动时行号会随文本一起滚走（应用默认开着自动换行）。代码引擎的行号本就自带，富文本 `.mh` 不提供。

## 全文替换

- **替换行**：查找面板新增「替换当前 / 全部替换」，回车即替换并跳到下一处。
- **口径一致**：命中位置按面板行级扫描的同一套匹配规则计算，保证「第 k 处」与引擎实际落点是同一处文本；全部替换走单事务，一步撤销即可整体回退。
- **落盘前校验**：查找之后文本又被改动时拒绝替换并提示重新查找，不会替到错位的内容上。
- 阅读态、预览类标签与富文本 `.mh` 不提供替换入口——`.mh` 的内容模型是 HTML，按去标签纯文本算出的偏移对不上源码，硬替会替错位置。

## 专注模式覆盖三引擎

- Markdown、代码、富文本 `.mh` 三个内核统一支持「当前段落保持清晰、其余行淡出」，段落按 Markdown 空行分隔，标题、表格、列表各自成整块不被拆散；悬停行恢复显示。
- 修复空行的行号亮度不齐：行号画在所在行内，会跟着该行的淡出透明度一起压暗，此前空行被豁免，导致它的行号在整列淡出的数字里始终亮着。空行没有正文，压暗对它除行号外没有任何可见影响。

## 查找与定位修复

- **正文不动 / 跳错行**：编辑与分栏态此前按渲染出的行元素序号推算文档行号，而编辑器只渲染可视区的行，一滚动序号就对不上，目标行在已渲染范围外时干脆无操作。现改为按行首偏移定位并垂直居中，点击命中行同样受益。
- **命中列表跟随**：键盘连按上下切换命中时，选中项会自动滚进结果列表视口（已在视野内则不动），避免抖动。

## 稳定性修复（v0.5.8 代码审查项）

- **外部改动检测误报**：自动保存与外部改动检查之间存在微任务竞态，写盘完成而「已保存」基线尚未落地时会误弹冲突对话框；现增加「磁盘内容等于当前缓冲区也不算冲突」的兜底，并给检查加上防重入闸门、修掉冲突框期间标签被关闭时的错误成功提示。
- **块格式选区边界**：整行拖选（或 Shift+↓）终点落在下一行行首时，此前会多改一行，现已回退。
- **`.mh` 标签切换卡顿**：不再给隐藏的富文本编辑器喂空串，避免每次离开/回到 `.mh` 标签都触发整篇重建；切换文档由两次解析降为一次。
