# 码克 v0.3.6

本版为预览体系升级版：SVG 与 HTML 预览支持缩放工具条与三模式，设置面板全面改版，并集中修复一批拖拽与边线细节。

## 预览

- **SVG 三模式**：.svg 文件与 HTML 一致，支持「编辑源码 / 分栏 / 阅读渲染」三种视图，不再只读。
- **HTML / SVG 缩放工具条**：30%–300% 缩放，步进 5%，点击百分比一键复位、双击回 100%；采用浏览器式缩放语义——只做视觉缩放、不重排，滚动统一交给外层查看区。
- **图片预览修复**：放大后顶部被裁切、滚动条滚不上去的问题修复。
- **查看区滚动条统一**：iframe 内滚动条与全局同规格，配色跟随明暗主题。

## 交互修复

- **拖动目录树宽度不再卡死**：svg/html 预览页签打开时，拖拽事件不再被 iframe 吞掉，可顺畅拖到目标宽度、松手即停；拖动中预览内容盒实时跟随宽度重排。
- **预览区左缘多余 1px 边线去除**：预览/阅读态不再让目录区视觉上变宽。
- **阅读模式内容区两侧边线去除**。
- **目录树竖边线**：特殊宽度下不再出现 2px 模糊线（亚像素取整）。
- **大纲滚动条**：预览/阅读模式下鼠标悬停进出样式异常修复。

## 设置面板

- **左右分类分栏改版**：外观 / 编辑器 / 快捷键 / 关于 四类目，参考 WorkBuddy 面板形态。
- **开关化**：自动保存、滚动同步改为滑块开关。
- **新增「显示功能栏」开关**：可隐藏编辑器顶部功能栏，正文区上移。
- **关于页**：品牌卡 + GitHub 项目地址 + 检查更新（结果内联展示，发现新版可一键前往发布页）。
- **快捷键页**：单卡分组重排，键帽右对齐，长组合键不再挤压文案。

## 大纲

- 层级标记改为**统一小圆点 + 字重分层**：H1 加粗、H2 中等、H3 常规、H4+ 弱化，替代原先仅靠灰阶色差的同形圆点。

## 其他

- 新增 Gitee 仓库同步工作流。
- 升级检测口径不变：应用内「关于」页与顶栏按钮均可手动检查更新。
