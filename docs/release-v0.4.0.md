# v0.4.0 发布说明

## 新特性

- **三模式位置同步**：编辑 / 分栏与阅读互相切换时精确锚定同一位置——视口顶边内容连续对齐（含被裁偏移还原），滚动到底部互切自动钉底，往返稳定不回跳。
- **全套中英双语**：设置 → 外观 → 「界面语言」一键切换（简体中文 / English），覆盖全部界面文案与编辑器功能栏提示；选择持久化，重启保留。
- **标签右键菜单升级**：每项配图标，并新增快捷键——Ctrl+W 关闭当前标签、Ctrl+Shift+W 关闭全部标签、F2 重命名当前文档（设置面板快捷键说明同步更新）。
- **编辑区行高对齐阅读态**：修复内核写死 20px 行距导致的视觉拥挤，行高自动跟随当前预览主题（default 1.6 / github 1.5 / win 1.75）。

## 问题修复

- 修复代码块内的 `#` 注释行（python/shell 等）被误判为标题而放大字号的问题。
- 修复设置里「滚动同步」开关不生效的问题（内核 scrollAuto 仅读挂载初值，现经重挂载生效，切换时滚动位置无感保留）。
- 修复滚动同步关闭时分栏预览可能停留在顶部的问题。

## 其他

- 依赖显式声明 `@codemirror/view` / `@codemirror/language`（与内核同源版本，扁平安装）。
