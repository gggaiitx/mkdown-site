## 我在用的本地 Markdown 编辑器：码克——离线、轻量，还替你守着文件

市面上 Markdown 编辑器不少，但选起来总有点别扭：要么逼你登录账号、文档上云，要么是个一两百 MB 的 Electron 大块头，开个记事本像在启动一台服务器。写技术方案、写笔记、写博客草稿，我想要的其实很简单——**一个纯本地的编辑器，打开快、不联网、别把我的文件搞坏。**

码克（MkDown）就是冲着这个来的。它是一个本地优先的 Markdown 编辑与阅读器：文档、图片、配置全部落在本机磁盘，不上云、不登录、不联网。装完即用，Windows 下是一个几 MB 的安装包。

> 📷 **图片占位 1**：主界面全貌——左侧文件树 + 中间分屏编辑（编辑/预览双栏）+ 右侧大纲面板，亮色主题

## 一个界面，三种状态

码克顶部就三个模式：**编辑、分屏、阅读**。

- **编辑态**：左写右看，分栏实时预览，滚动同步，改哪边另一边都跟得上；
- **阅读态**：沉浸式通栏阅读，配合大纲面板点击跳转，当阅读器用毫无压力；
- **多标签页** + 脏标记：开着几个文档清清楚楚，没保存的带 ● 提示，关错了有确认兜底。

> 📷 **图片占位 2**：分屏编辑态特写（左边 Markdown 源码、右边实时预览），最好带 Mermaid 图或 KaTeX 公式的内容

大纲面板值得一提：随内容实时更新，宽度可以拖拽（拖到最右隐藏，拖边线复原），写长文档时它就是你的目录。重启应用还会恢复上次的标签页和光标位置——接着上次的进度继续写，无缝。

## 它还顺便把 Word 和 Excel 预览了

工作区里不可能只有 `.md`。码克对文件做了分流：文本类进编辑器，**docx / xlsx / 图片进应用内只读预览**，其余（pdf、ppt、音视频……）自动交给系统默认程序。

- **Word**：保留纸张视觉、页眉页脚、图片的渲染效果；
- **Excel**：多工作表页签切换的表格预览；
- **图片**：png / jpg / gif / webp / svg 全支持，带缩放工具条。

写方案时边上放着一份需求 docx，不用切出去另开 WPS，点开就看——这个小体验一旦习惯了就回不去。

> 📷 **图片占位 3**：docx 预览效果（一张带页眉页脚的 Word 文档在应用内打开的截图）

## 截图粘贴，图片自动落盘

写文档免不了贴图。码克直接**截图 → Ctrl+V**，图片自动存到文档同级的 `assets/` 目录，文档里写的是相对路径。这意味着整个文件夹拷去哪、发给别人、放进网盘，图片链接都不会断。本地优先不是把功能砍掉，是把数据交还给你自己保管。

> 📷 **图片占位 4**：粘贴截图后的 assets 目录 + 文档内相对路径引用的对比截图

## 流程图和公式，断网也能画

很多编辑器的 Mermaid 流程图和 KaTeX 公式是运行时从 CDN 在线加载的——网一断，图就渲染不出来。码克把这两样**直接打包进了应用**，写技术方案画架构图、写学习笔记敲公式，飞机上、高铁上、内网环境里，一样能渲染。

这是一个不起眼但很能说明产品态度的细节：所谓"离线优先"，不是界面上写句话，而是把每一处"悄悄联网"的依赖都揪出来替换掉。

> 📷 **图片占位 5**：Mermaid 流程图 + KaTeX 数学公式的渲染效果特写

## 你的文件，它比你还在意

本地编辑器最致命的事故不是闪退，而是把文件写坏。码克在这层做得很偏执：

- **原子写**：先写临时文件再原子替换，写一半断电也不毁原文件；
- **编码探测**：UTF-8 / UTF-16 / GBK 自动识别，非 UTF-8 文件禁止就地写回——宁可拦下保存，也不给你存一盘乱码；
- **删除进回收站**：删错有后悔药；
- **自动保存可开关**：停顿即落盘，但决定权在你。

另外全局搜索（文件名 + 正文，支持正则）、多工作区一键切换、新建文档套模板，这些日常刚需也都齐了。

> 📷 **图片占位 6**：全局搜索结果高亮界面，或暗色主题下的整体效果

## 轻量这件事，是技术选出来的

码克没用 Electron，外壳是 Rust + Tauri，渲染用系统自带的 WebView。换来的结果很直接：**安装包几 MB，秒开，内存占用低**。不为"记事本"级别的需求背一整个浏览器，这笔账算得很清楚。

安全上也留了边界：HTML 文件的预览刻意不执行其中的脚本（预览是"看"，不是"运行"），本地资源访问按工作区动态授权。一个不上云的应用，反而更需要把本地的安全模型想清楚。

## 适合谁，不适合谁

**适合**：写方案/文档/博客的技术人，需要本地管理大量 Markdown 的笔记党，在意隐私不想文档上云的用户，内网/离线环境的使用场景。

**不适合**：需要所见即所得编辑的（码克是源码 + 预览路线）、需要多端云同步的（它压根不上云，同步请自带网盘）。
