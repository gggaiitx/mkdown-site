# 码克 v0.7.3

这一版给「书桌」欢迎页收尾，并把配色扩到八套：新增取自 logo 的晴蓝 / 星蓝；书桌左栏目录树可以拖宽度、拖到最左收起，继续工作卡的文档纸会自己打字并循环上滚。

## 新增配色（设置 → 外观 → 配色）

- 明色新增「晴蓝」、暗色新增「星蓝」，取自 logo 渐变的冰蓝 → 天蓝 → 深海军蓝；亮暗成对，沿用两种模式各记一套的规则。
- 主按钮的前景色改为跟配色走：亮蓝底上用深墨字，避免白字掉到对比度下限以下；原有六套配色外观不变。
- Markdown 预览面、书桌环境光、编辑器选区与光标一并接入新配色。

## 欢迎页 · 书桌

- 左栏目录树可拖宽（200–360px，上限随窗口宽度收紧），向左拖到 120px 以内松手即收起；收起后窗口左缘出现窄把手，一点就按拖拽前的宽度重新展开。
- 书桌版不再叠画拖宽手柄线，边缘反馈交给左栏自身的 1px 边框；全局侧栏的拖宽交互维持原样。
- 「继续写作」卡改名「继续工作」，按钮文案按文件类型给出「继续写作 / 继续编码 / 继续查阅」。
- 文档纸卡换成打字机式循环预览：正文逐字打入、超出纸面时整体上滚，读完停一下淡出、再从开头继续；内容不满一屏时打完即停。
- 纸卡顶部加了金属卡针，标题改单行省略；两列与单列档给纸卡和正文窗口补了高度上限，长文档不再把整张卡撑高。
- 新建磁贴悬停浮出 MD / MH / TXT / TPL / DIR / NEW 水印；「继续工作」按钮加了一道周期性柔光。
- 「本周」柱状图悬停显示当日改动数，柱子带轻微回弹；最近改动改用完整路径做 key，同名文件不再互相串位。
- 页脚改为三栏：左「Design by Shenco」、中版本号与更新状态、右引擎说明，版本号落在内容带的中心线上。
- 工作区统计超过 6 万个节点时数字前加「≥」，悬停说明统计范围。
- 目录树里的文件单击 / 双击 / 新建后打开都走全局同一条打开链路，进入编辑器时自动接上全局侧栏。

## 欢迎页 · 自适应与窗口

- 书桌版的进入与退出阈值分开（1000 × 520 进入、960 × 480 退出），把窗口拖在边界上不再反复重建书桌与内嵌目录树。
- 左栏的出现与收起同样带回差（1240 / 1200），并新增高度门槛（≥640）：矮窗下不再让纵向目录树把五张卡顶出视口。
- 书桌版左栏的入场 / 收起带宽度过渡，横向档把右侧五张卡推开、竖向档只淡入。

## 提示与细节

- 应用内提示统一走自绘气泡：默认单行不折行、超长末尾省略；行首带类型图标时箭头对准图标。欢迎页与目录树里原先的原生 `title` 全部替换。
- 顶栏「文件」下拉展开时给内容区加一层轻遮罩，突出菜单本体。
- macOS：为老版 WebKit 补上 `color-mix` 失效时的实色兜底（主按钮、柱状图、焦点环）；「在文件夹中显示」在 macOS 上显示为「在访达中显示」。

## 已知限制

- macOS 产物仍未做代码签名与公证，首次打开需右键「打开」绕过 Gatekeeper。
- 欢迎页书桌版目录树的宽度与收起状态只在本次会话有效，不落盘（与全局侧栏一致）。
