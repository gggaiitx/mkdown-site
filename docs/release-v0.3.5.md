# 码克 v0.3.5

本版为编辑体验细节打磨版，集中处理编辑区边框缝隙、滚动条行为与标题排版。

## 编辑区

- **去除编辑区四边多余边框**：md-editor 根容器自带的 1px 边框改用面板色融入应用 chrome，不再与标签栏底线、侧栏缘线、状态栏顶线叠加成双线框；四角交界处不再出现亚像素缝隙。
- **代码块头部栏层级修复**：代码块的「复制 / 折叠」头部栏不再浮在搜索面板等应用浮层之上。
- **功能栏底线与侧栏边线无缝接拢**：功能栏（B/I/U 工具行）底线左右各外扩 1px 盖住边框列，与目录树边线、右缘线端点相接，中间不再有浅色断带。
- **首标题上方留白压掉**：分栏预览与阅读态的首个标题不再叠加主题顶部边距（修复选择器未命中 v7 预览结构导致规则失效的问题），首屏顶部落位与正文一致。

## 滚动条

- **编辑态滚动条滑槽透明**：只保留滑块本身，不再有灰色滑槽底。
- **目录树 / 大纲滚动条统一**：改用标准常驻细滚动条，两侧规格完全一致；鼠标悬停、按住拖动时**宽度恒定不变**（不再随 Fluent 悬浮行为展宽）。

## 标题排版（编辑态）

- 以 `#` 开头的标题行字号调整为 **19px**，行距与预览主题一致（1.75），编辑/预览密度统一。

## 界面

- 顶栏按钮重新分组：**新建**划入「新建 / 保存 / 另存为」文档操作组，与「打开文件 / 打开工作区」组分隔。
- 工作区隐藏后的左缘复原条收窄至 4px，复原边线贴齐编辑区，与各横向分隔线接拢。

## 下载

- Windows：NSIS 安装包（x64），自带卸载程序，注册到系统「应用与功能」，卸载保留用户数据。
- macOS：Apple 芯片 / Intel 双架构 dmg（未签名，首次打开需右键「打开」绕过 Gatekeeper）。

其他获取方式见 [官网下载页](https://mkdown.opensites.net)。
