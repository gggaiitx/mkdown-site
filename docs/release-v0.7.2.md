# 码克 v0.7.2

这一版把「全局字体」做成真正的全局设置：外观里选一次，界面与正文一起跟随；设置面板的下拉与滑条统一重做，并补齐了七条设置说明。同时修掉 macOS 上「用码克打开」文件打不开的问题。

## macOS「用码克打开」文件

- 双击关联文件 / 右键「打开方式」现在会把文件送进主窗口：macOS 走 Apple Event（`RunEvent::Opened`），与 Windows 的命令行参数、单实例转发汇入同一条派发通路。
- 启动瞬间送达的文件先入队，前端监听就绪后再取走，不会因为监听器尚未注册而丢掉；文件所在目录同步加入本次会话授权。
- 已在 Rust 侧补 file:// URL 解析、非文件与不存在路径过滤、前端就绪前后取件顺序的单测。

## 全局字体（设置 → 外观）

- 新增字体下拉：应用默认 / 系统默认 / 系统已安装字体，可按名称搜索，每一项按自己的字体预览；也支持直接输入自定义字体栈。
- 界面与正文一起跟随：顶栏、标签栏、Markdown / Markhtml 编辑与预览、表格预览、代码编辑器都接入全局字体；代码块仍保持等宽。
- 选择「应用默认」不覆盖任何原有字体栈，升级后外观与上一版一致；切换立即生效并持久化。
- 系统字体枚举走 Rust：Windows 用 DirectWrite、macOS 用 CoreText；首次展开才加载，前端模块级缓存。

## 设置面板

- 外观、编辑器、导出、操作四页共 13 个原生 `<select>` 全部换成应用内下拉：宽度以 200px 起步，长选项最多 320px，右缘对齐触发钮，不再顶出设置面板；超长文案省略、悬停看全文。
- 下拉支持键盘上下键 / Home / End / Enter；Esc 只关下拉，不会连带关闭设置面板。字体选择器复用同一套外观，只保留自己的搜索框。
- 滑条与下拉统一 200px 宽且右缘对齐；设置-编辑器页所有行按 42px 行高排布，开关行不再比下拉行紧。
- 补齐七条设置说明：配色、预览主题、版式、字号、大纲、Word 导出引擎、Word 导入保真度，中英文同步。
- 关于页「项目地址」下新增「更新日志」，直达 GitHub Releases。

## 已知限制

- macOS 产物仍未做代码签名与公证，首次打开需右键「打开」绕过 Gatekeeper。
- 本机为 Windows，macOS 的「用…打开」实机链路未在本机跑过；建议在 Apple 芯片 / Intel 两份产物上各做一次双击关联文件回归。
