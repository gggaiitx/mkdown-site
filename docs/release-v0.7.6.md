# 码克 v0.7.6

这一版把「写完发出去」这一段接上了：Markdown 右键可以直接复制成公众号 / 知乎格式，文件菜单多了导出长图。另外修掉了 Word 导出里公式降级重复一遍的问题。

## 复制为公众号 / 知乎

- **入口**：md 编辑 / 分栏窗格右键「复制」升成二级飞窗——复制原文、复制为公众号、复制为知乎。整篇复制，不动原文件；内容取 CodeMirror 实时文档，右键前一瞬打的字也算。
- **公众号**：微信编辑器会重建 h1–h6 / pre / ul / ol / li 这些块，挂在上面的样式会一起丢。所以标题降成带内联样式的段落，代码块自拼成 section + 换行 + 不换行空格（微信没有代码块类型），列表补上 • / 1. 前缀和悬挂缩进，引用与 figure 拆成 section。
- **知乎**：代码块整理成知乎认的 `pre[lang]`（语言只写在 code.class 上、或再套一层 code，都会落成普通正文）；列表项里的代码块提到块级，不再黏成一行；表格换成 `data-draft-*` 草稿结构、首行表头在 tbody 里；正文不写死文字颜色，暗色模式不会糊。
- **降级都说清楚**：公式在公众号里给 TeX 行内代码、在知乎给 `$…$` / `$$…$$`；图表给源码块；本地图片（asset:// / 相对路径）平台取不到，留明确占位并计数。复制完成后提示语会写清这次降级了什么，不静默。
- **取源不重复**：KaTeX 源码优先取 annotation，没有就取 `<math>` 的裸文本子节点，绝不整棵 textContent——那会把 MathML 与源码拼成「Emc2E=mc^2」。

## 导出长图

- **文件 → 导出 → 导出长图**：宽度自适应当前内容版式——窄 / 中 / 宽 / 100% 与阅读栏的实际宽度，量的是屏幕上那一栏的内容盒（仅编辑态量源码栏），四周补 32px 白边。
- **所见一致**：主题 CSS、全局字号与字体（`:root` 上的行内变量）一并带进离屏文档；md 补 `.md-editor` 外壳、.mh 补 `.w-e-text-container` 链，引用块 / 代码块 / 表格的底色不掉。
- **图片与图表**：本地图片连 asset:// 一起内联成 data URI；mermaid 保留渲染后的图，并剔除悬浮的操作条（否则静态图里会露出一排复制 / 放大图标）。
- **两趟截图**：先让 Edge 把整页高度写进标题、量准，再按宽 × 高整页截图；DPR 随高度按 2 / 1.5 / 1 下调控制体积。单张上限 40000px，超出会提示拆分文件。
- **适用范围**：.md 与 .mh 可用；代码、HTML、SVG 标签没有渲染稿，菜单项置灰。

## 修复

- Word 导出里公式光栅化失败时的降级文本与复制共用同一套取源逻辑，不再出现公式重复一遍的「Emc2E=mc^2」。
- 导出 PDF 的 Edge 定位抽成共用函数，报错信息照旧说明可改走「打印 PDF」。

## 已知限制

- 公众号 / 知乎的粘贴效果取决于平台当前版本。本版按实测的清洗规则适配：公众号的代码块是自拼版式，粘过去不能再当代码块编辑；平台改版后可能需要再调。
- 本地图片在复制时不会上传，平台里需要重新上传；图表与公式只能以源码保留。
- 长图导出依赖系统 Edge，目前仅 Windows；macOS 上导出 PDF 同样受限（既有行为）。
- 长图单张上限 40000px，超长文档请拆成多个文件分别导出。
