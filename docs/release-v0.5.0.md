# v0.5.0 发布说明

## 新特性

- **代码编辑引擎**：新增 CodeMirror 6 自建代码编辑器，`.py / .rs / .ts / .js / .json / .sql / .css / .go / .sh / .toml / .yaml` 等 30 余种扩展名打开即语法高亮，不再被误渲染为 Markdown；语言包按需懒加载，首屏体积零增加。
- **纯文本不再误渲染**：`.txt / .log / .csv / .tsv` 及无扩展名文本文件改为纯文本编辑，`#`、`**`、`-` 等字符保持字面量原样。
- **HTML / SVG 源码高亮**：HTML 与 SVG 的编辑态切换为代码高亮（保留分栏与阅读模式——分栏左侧源码右侧实时渲染，阅读态仍由内置 Frame 呈现）。
- **拖拽打开扩展**：拖入代码、文本、HTML、SVG 文件即可直接打开编辑，源码类文件默认进编辑态。
- **语法配色升级**：自建 GitHub Light / GitHub Dark 双主题配色（关键词红、函数紫、类型橙、字符串浅蓝、注释灰斜体），亮暗主题跟随切换；选区底色清晰可见。
- **macOS 快捷键适配**：快捷键提示按平台显示（⌘/⌥/⇧ 或 Ctrl/Alt/Shift），模式切换 ⌥E/⌥W/⌥R 在 Mac 上可用（Option 死字符键位已兼容）。
- **界面字号固定**：顶栏、标签栏、状态栏、目录树等界面文字不再随「字号」设置缩放，字号设置仅作用于编辑区与预览正文。

## 问题修复

- 修复代码编辑器拖选无底色的问题（当前行高亮遮挡选区层，改为半透明当前行高亮）。
- 修复 HTML/SVG/代码文件的 Markdown 格式快捷键误包裹、美化误改写问题（相关操作按文件类型自动关闭并给出提示）。

## 其他

- 依赖新增 CodeMirror 6 官方语言包与 `@lezer/highlight`（全部按需动态加载）；移除 `@codemirror/theme-one-dark`。
