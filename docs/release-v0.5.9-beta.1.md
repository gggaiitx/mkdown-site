# 码克 v0.5.9-beta.1

Beta 版，只带一项修复：v0.5.9 的 Markdown 编辑窗格行号在「页面全屏」下会跑位。用于实测确认，不进正式版通道——官网与 README 的下载入口仍指向 v0.5.9。

## 行号：页面全屏后跑位修复

- **症状**：编辑器进入页面全屏后，行号不再贴着窗格左边界；退出全屏后行号整列消失，要关掉再打开一次行号开关才恢复。
- **原因**：行号要贴住窗格左边界，得先量出「窗格左缘到正文行」这段留白——它是正文居中限宽算出来的动态值，只能由脚本量。此前这个量只挂在编辑器外层容器的尺寸回调上，而页面全屏是把编辑器自身改成铺满视口的固定层，外层容器的大小一点没变，于是量测根本不重跑，用的还是上一个状态的旧值：进全屏拉得不够（贴不到边），退全屏拉得过量（数字被拽出窗格左沿、被裁掉，看起来就是行号没了）。切一次行号开关恰好会补测，所以「取消再打开就好了」只是假象。
- **修复**：量测改挂到会真正变宽的那几个盒子上（编辑器根与滚动区，并随编辑器重建自动重挂），另外直接盯住全屏状态的样式类变化补测一次，全屏后版式二次结算时再补一帧；行号开启期间保留一道低频兜底校验，只在量到的值确实变了才写样式。
- **影响面**：仅 Markdown 编辑窗格的行号显示，不涉及内容、快捷键与其他内核（代码引擎行号自带，富文本 `.mh` 不提供行号）。
