# 码克 v0.7.0-patch.1

v0.7.0 的补丁版，集中在「目录树更好用、右键行为收敛」这一条线：右键菜单按目标分流并补齐提示，树内新增一套键盘操作，新建文件名跟随当前内核，刷新与落盘即时回读目录树。

## 目录树右键按目标分流

- **三套菜单**：文件（打开 / 在编辑器中打开 / 系统程序 / 定位 / 复制路径·相对路径 / 重命名 / 删除）、文件夹（新建两件 / 展开折叠 / 刷新 / 打开位置 / 复制 / 重命名 / 删除）、空白区（新建两件 / 刷新 / 打开位置 / 复制路径）。补图标、分隔线与快捷键提示，菜单项与真实绑定严格一致。
- **定位与打开位置分开**：「定位」把文件滚动进可视区并选中；「打开位置」调起系统文件管理器到所在目录。
- **复制路径两档**：Ctrl+C 复制绝对路径，Ctrl+Alt+C 复制相对工作区的路径，菜单里同步给出提示。
- **空工作区右键直接不弹**：未打开工作区时不会凭空出菜单。

## 树内快捷键

- **Enter** 打开 / 展开、**Ctrl+Enter** 在编辑器中打开、**Shift+Enter** 用系统程序打开、**Ctrl+R** 刷新、**Ctrl+Shift+R** 打开所在位置、**Delete** 删除、**F2** 重命名。
- **F2 就近派发**：树有选中节点时改由树节点处理重命名，否则回落到当前标签重命名，避免两处打架。
- 动作函数统一「节点参数」式，菜单与键盘共用同一套实现，提示文案与真实绑定一一对应。

## 全局右键守卫

- 除自绘菜单区域（及输入框 / 链接 / 图片 / 带 `data-native-ctx` 的元素）外，统一禁用 WebView 原生右键菜单；自绘菜单在冒泡阶段收口，命中可编辑区与链接图片则放行系统菜单。
- 边界：链接与图片上的系统「复制链接地址 / 图片另存为」仍由系统处理，应用菜单给不出等价项。

## 新建文件名跟随内核

- 默认名取「当前内核后缀」：先取路径 / 草稿路径的扩展名，取不到再按文档类型（md→.md、mh→.mh、html→.html、svg→.svg、代码·文本→.txt）。
- AppDialog 输入框打开即选中主名（不含扩展名），新建与重命名手感一致。

## 刷新与落盘即时回读

- 右键 / Ctrl+R 刷新与头部刷新按钮共用同一份实现（图标旋转 + 整树淡入），不再各写一套。
- 另存为落在当前工作区内时自动回读目录树，新文件即时可见，不必手动刷新。

## 已知限制

- macOS 产物仍未做代码签名与公证，首次打开需右键「打开」绕过 Gatekeeper。
