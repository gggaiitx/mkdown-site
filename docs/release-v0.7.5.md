# 码克 v0.7.5

这一版把码猫从书桌带进了编辑器：写作、阅读、保存它都在旁边。顺带把欢迎书桌的版式收了一轮。

## 码猫 · 跟着你写作和阅读

- **编辑器右下角常驻**：宽度 52px，猫脚正好压在状态栏上沿；窗口窄于 640px 时自动让位收起。轻提示抬到它头顶，右下角回顶钮向左让开，三个东西不再叠在一起。
- **六张表情**：平时坐着、悬停举爪、点击眯眼笑、半分钟没动打哈欠，新增**阅读捧书**与**保存失败炸毛**。写作专注、思考、阅读跟随用轻微前倾/侧倾区分姿态，不是骨骼动画。
- **写作时安静看你打字**：不再抢在输入中间说话，停下来才提示。25 分钟提醒起身、两分钟没动提示别卡着、每 500 字记一笔、未保存与未命名各催一次、超过 3000 字提示右侧大纲可跳章节。
- **阅读时跟着滚动方向轻晃**：读到一半、看到文末各有一次回应；连续阅读八分钟提醒远眺。内容不足一屏不算「看了一半」。
- **保存与导出有回应**：手动保存跳一下、导出成功说一声；**保存失败一定会说**，编码装不下时直接建议另存 UTF-8——这条不受话量档位影响。
- **话量三档与静音**：设置 → 操作 → 码猫可选安静 / 标准 / 话痨；安静档只保留保存失败这类必说项。右键可静音 30 分钟，也可以摸摸头、切专注模式、回到顶部、直达设置或直接藏起它。
- **功能小贴士只出现一次**：标签数到 3、进入页面全屏、预览工具条、自动保存入口等，每项跨文档、跨启动只提示一次，记在设置文件里。
- **双击**：书桌页打开「继续写作」；编辑器阅读态回到顶部，写作/分栏态切换专注模式。

## 欢迎书桌

- 宽屏内容带从 1440 放到 **1680**，超宽屏不再大片留白，卡片也不会贴边。
- 「继续写作」摘要按左栏可用高度**取整行裁切**：窗口变矮少显示一行并带省略号，不再出现半截字。
- 新建磁贴补了一行**格式与数量信息**（.md / .mh / 模板数 / 工作区数），只在宽屏且窗口够高时显示。
- 「最近改动」不再按高度硬截断，整份列表可上下滚动；回到书桌或窗口重新获得焦点时自动重扫工作区，30 秒内的重复触发合并。

## 修复

- 炸毛表情不会被悬停或阅读抢走计时后**一直挂脸上**，移开指针也不会把保存失败的原因一起收掉。
- 阅读工具条的 20 秒提示定时器退出阅读后一并取消，不会跑到写作态弹「底部悬停有预览工具条」。
- 长按码猫后把指针拖出按钮再松手，下一次点击不再被吞。
- 安静档 / 静音期间不再积压提示，解除后不会补发过期内容。
- 启动恢复会话不再误报「开了 N 个标签」。
- 窗口聚焦重扫工作区加了 30 秒阈值与进行中保护，大工作区不会每次 Alt-Tab 都全量扫一遍。

## 已知限制

- 编辑器浮层在窗口宽度 < 640px 时隐藏；欢迎书桌在 < 460px 时隐藏。
- 码猫只跟随有正文的标签，docx / xlsx / 图片这类只读预览不出现。
- 阅读进度只统计 Markdown 阅读 / 分栏、Markhtml 阅读态与代码滚动区；内容不足一屏不判断进度。
- 页面全屏时状态栏被正文覆盖，猫仍停在距窗口底 24px 的位置。
- 提醒在窗口最小化或不在前台时跳过，不补发，等下个整点或饭点。
- 功能小贴士每项只出现一次，目前没有「重看提示」的入口。
