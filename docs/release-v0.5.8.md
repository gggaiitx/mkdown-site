# 码克 v0.5.8

本版聚焦「就地完成编辑动作」：表格与常用格式的操作入口从顶栏迁入编辑区右键菜单，并补上专注模式与外部修改冲突检测两项高频诉求。

## 编辑区右键菜单

- **入口迁移**：表格编辑不再占顶栏位置；在编辑区右键即可唤起菜单（阅读态不接管，分栏预览窗格维持原状）。
- **二级飞窗**：「表格」「标题」两组收进子菜单，一级只留常用动作——刷新、插入表格、加粗、斜体、引用、代码块、行内代码、无序/有序/任务列表、链接。飞窗靠屏幕右缘自动翻向左侧、靠下缘自动上移。
- **作用于选中内容**：右键落在已有选区内不再拆掉选区，包裹型动作直接作用于选中文字；无选区时作用于光标所在整行（中文没有词边界，整行是最小可预期单位）。
- **空段落带示例**：在空行上执行标题/引用/列表/任务项，会补一段示例文字并置于选中态，接着打字即替换，不再只留一个裸标记。
- **与快捷键同源**：菜单与 Ctrl+B/I/K、Ctrl+1~6、Ctrl+Shift+C/I 共用同一张动作表，避免两处前后缀漂移。

## 表格编辑

- **两档对齐**：「整理表格」默认只做紧凑规整（统一为 `| a | b |`、剥多余空白、分隔行规整为 `---` / `:---:`），不再补齐列宽，长文本表不会被撑成数百字符宽行；「等宽对齐」按中日韩字符双宽计算，仅对窄表开放，宽表该项置灰。
- **行列操作**：上/下插入行、左/右插入列、删除当前行/列；插入与删除都会保留分隔行里的对齐冒号（此前加一行会把对齐弄丢）。
- **粘贴转换**：从表格软件复制的 TSV/CSV 粘贴进 Markdown 自动转成表格；右键「插入表格」生成骨架并独占新行。

## 专注模式

- 当前段落保持清晰、其余行淡出，段落按 Markdown 空行分隔，标题、表格、列表各自成整块不被拆散；悬停行恢复显示。
- 设置「编辑器」页与编辑区右键菜单均可切换（右键项带当前状态勾选标记），开关持久化保存。

## 外部修改冲突检测

- 文件被其他程序改动时：本地没有未保存修改则静默按磁盘新版本载入并提示；本地有未保存修改则弹出对话框，由你选择「重新加载」（丢弃本地改动）或「保留我的改动」（双方都不动，下次保存覆盖外部改动）。
- 判据为「磁盘 mtime 变化后再读内容比对基线」，因此应用自身保存不会误报；窗口重新获得前台时立即检查，前台期间定期复查。

## 稳定性修复

- **编辑区右键与表格粘贴偶发失效**：此前借用内核 `domEventHandlers` 一次性注册，内核实现内部对未就绪视图是静默跳过、且扩展会被配置重建覆盖，导致切换标签后「有时右键没反应」；现改绑常驻根节点的原生捕获监听，并在处理时才取当前视图。
- **页面全屏后浮层看不见**：内核页面全屏层为 `z-index: 10000` 的铺满定位层，会整片盖住右键菜单、搜索面板与轻提示；将这类应用浮层抬到 10100 层级带，仍低于对话框与气泡提示。
- **格式动作后焦点**：菜单项点击后焦点会停在按钮上，现在执行完把焦点交还编辑区，可直接接着打字。

## 预览与系统集成

- **PDF 应用内预览**：PDF 文件在标签内直接预览，无需外部阅读器。
- **Windows 右键与文件关联**：安装后可在资源管理器右键用码克打开 Markdown 文件，双击 `.md` / `.mh` 等关联格式直接启动。
