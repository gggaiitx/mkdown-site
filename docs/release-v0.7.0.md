# 码克 v0.7.0

这一版把「从系统借来的东西」收回自己手里，并把外观拆成两个正交维度。

最直观的变化是**文件对话框**：打开文件、打开/新建工作区、另存为、导出、Word 转换全部换成应用内选择器，不再弹系统资源管理器；其次是**主题**变成「模式 × 配色」，跟随系统之外另有明暗各三套；再就是 Markdown 预览终于能渲染 README 里那些 `<div align="center">`、`<details>`、`<img width=…>` 的原生 HTML。

## 新：应用内文件与文件夹选择器

- 一套选择器顶五处入口：**打开文件 / 打开工作区 / 新建工作区 / 另存为 / 导出（HTML·Word·PDF·PNG）/ Word 转换选文件**。左栏是快捷位置（主目录、文档、桌面、下载）与盘符或根目录，顶部是可手输的路径栏，隐藏项默认不列、按开关显示。
- **新建工作区一步到位**：名称与存放位置在同一个界面里填，确认即在该位置建目录并打开。原先「先选目录、再填名字」两步走，选完目录才发现名字要改。
- 保存模式会**补默认扩展名**、目录同名时提示「将替换」、目标太多时明确告知只列出了前 1000 条（不是目录里就这些）。
- 选择器本身**只列路径、不做授权**：授权点后移到真正的动作上（开工作区、打开文件、写入、导出各自补登记），边界没有放宽，但"选完打不开"这类中间态也不会出现。
- 顺带解掉历史包袱：macOS 上系统面板的扩展名是**硬白名单**，`*` 不算通配符，曾经出现过「打开文件里 .txt/.mh/代码文件全被灰掉」。

## 新：主题 = 模式 × 配色

- **模式**：跟随系统 / 亮色 / 暗色。跟随系统时白天夜晚自动切换，但两种模式下的配色**各记各的**，夜里选过暖褐，白天不会跟着变成暖色。
- **明色三套**：素白（原外观）、冷灰、米黄；**暗色三套**：石墨（原外观）、午夜蓝、暖褐。
- 实现上 `data-theme` 只表达明暗、`data-palette` 只表达配色，两个维度正交，所以正文、代码高亮、选区光标、预览主题互不干扰。默认两套与升级前**视觉零变化**。
- 旧配置自动迁移：只有 `theme` 的老设置按原选择落成手动模式，不会被「跟随系统」悄悄改掉。

## 新：Markdown 混排原生 HTML

- README 型文档里的 `<div align="center">`、`<table>`、`<details>`、`<img width=…>` 现在真的渲染成 DOM，不再是一堆转义后的尖括号。
- 打开 HTML 直通的同时自带净化：DOMPurify 走 html + svg + mathMl 三档（**必须带 mathMl**，否则 KaTeX 的公式层会被剥掉），并把原生 `<img>` 的相对路径一并改写成 `asset://`，与 md 语法图片同口径。
- 净化只对**真的含原生 HTML** 的文档生效：纯 Markdown（含公式、Mermaid、代码块）不做 DOM 解析，不付这份开销。

## 新：预览区「回到顶部」

- 长文档（Markdown 阅读/分栏预览、Markhtml 正文）向下滚过一屏后，右下角浮出回顶小圆钮，点一下**带缓动**回顶，中途自己滚滚轮会立刻让位。
- 两档显现方式：自适应（指针移入右下角才浮出，平时不压正文，出厂默认）/ 一直显示（滚动后常驻）。开关与档位在**设置 → 操作 → 回到顶部**。
- 分栏态只驱动编辑侧，由内核的比例同步带动预览侧——两栏各跑一条动画会互相覆盖，看着就是抖。

## 新：顶栏「文件」菜单与快捷键

- 原「输出」下拉并入**文件**菜单：新建（内嵌 md / mh / txt 三档开关，点哪个就建哪种）、打开文件、新建工作区、打开工作区，以及导出 / 打印 / Word 转换三组。
- 侧栏开关**恒钉在最左**，图标随显隐切换（工作区头部那颗「隐藏」按钮撤掉，少一个只进不出的入口）。
- 顶栏新增**自动保存**快捷开关，与设置里是同一个字段。
- 新快捷键：`⌘⇧N` / `Ctrl+Shift+N` 新建工作区、`⌘⇧O` / `Ctrl+Shift+O` 打开工作区、`⌘⇧M` / `⌘⇧H` Word 转 MD / MH。

## 改：几个默认值

- **正文默认字号 15 → 13**（仅影响新装；老用户的字号设置不动）。
- **侧栏默认收起**：启动恢复上次工作区时也保持收起，只有主动打开、切换或新建工作区才展开。
- **点弹窗外不再关闭**：出厂改为只能用「取消 / 关闭」、右上角 × 或 Esc 关；想恢复旧习惯可在设置 → 操作里打开「点弹窗外关闭」，全应用弹窗共用这一项。
- ←/→ 同目录切换**加了开关**（默认开）。文本按 md / mh / html / svg / 同扩展名分组，图片、PDF、Word、Excel 各自一组；脏标签不切换。
- 1px 细线改为按设备像素折算（`--mk-dpr`）：125% / 150% 缩放下目录树与大纲的边线不再出现「某些宽度变 2px」。

## 修

- **行内原生 HTML 不走净化**：探测规则挂在了 `block` 之后，此时 inline 还没解析，`<img onerror=…>` 这类行内 HTML 一律判不出。实测改前 `onerror` 会真的执行、且行内原生 `<img>` 的相对路径也没被改写成 `asset://`；改到 `inline` 之后两者一并解决。
- **跨平台路径拼接**：新增 `utils/pathJoin.ts`，替换 6 处硬编码反斜杠（另存为 / 导出落盘、相对图片转 `asset://`、Word 转 draftPath、预览区文档互链）。写死 `\` 在 macOS / Linux 上会把「目录 + 文件名」拼成**一个文件名**，另存为静默写到上一层目录、图片直接 404。
- 弹窗里焦点落在按钮上时按回车不再同时触发按钮与提交。
- 悬浮提示被视口夹到锚点上方时，箭头跟着切到底部，不再指反。

## 已知限制

- `html: true` 的固有代价：正文里未转义的 `List<String>`、`<T>` 会被当成标签吞掉（GitHub 同款行为）。要当文字显示请用反引号或 `&lt;`。
- 选择器单目录最多列 1000 条（超出有提示）；隐藏项默认不列，需点左下开关。
- PDF 直接导出仍依赖系统 Edge（Chromium 打印引擎），macOS 上请用「打印 PDF」。
- macOS 产物仍未做代码签名与公证，首次打开需右键「打开」绕过 Gatekeeper。
- 本版未逐项人工回归，macOS 侧无真机验证：重点需实测「另存为落点」「相对路径图片」「导出 HTML」三项。
