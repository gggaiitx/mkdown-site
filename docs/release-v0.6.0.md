# 码克 v0.6.0

本版把「换档不丢东西」和「全屏里也能办完事」两件事做完：三个编辑内核改为常驻，切文档切模式不再丢撤销栈与滚动位置；页面全屏打通三个内核与三种形态，功能栏里能直接切模式、切视图；大纲新增贴视口右缘的清新浮标。同时把编辑区右键菜单扩到代码页与富文本页，并清掉一批界面一致性与无障碍欠账。

## 三个编辑内核改为常驻

- **切档不再丢东西**：Markdown / 代码 / 富文本 `.mh` 三个内核改为「首次用到才挂、此后常驻并只切显隐」。此前在 `.mh` 与 Markdown 之间来回切会销毁重建整个内核，撤销栈与滚动位置一起没了；现在切走再切回，undo 历史和你看的那一行都还在。
- **位置按标签保存**：隐藏期间滚动位置归零是浏览器行为，故滚动位由各内核按标签捕获与恢复，切回来落回原处。

## 页面全屏打通三引擎三形态

- **三条入口同源**：F11、标签栏右键「全屏」、编辑区右键「全屏」走同一个分发，Markdown 的编辑 / 分栏 / 阅读三态与代码、富文本都覆盖。
- **全屏里也能切模式**：Markdown 功能栏在全屏态新增「分栏预览」按钮；富文本 `.mh` 全屏时功能栏给出编辑态 ⇄ 阅读态的切换入口。顶栏被全屏层盖住不再是死路。
- **跨模式接力**：编辑态按了 F11 再切阅读态，全屏不再凭空丢失（内核的全屏挂在会被换掉的编辑器节点上，现改接到引擎根节点并在切回时交还）。
- **全屏时的目录**：右侧大纲面板会被全屏层盖住，故全屏阅读时改由右缘大纲浮标承担目录。

## 大纲「清新」浮标

- **设置「外观」新增两档**：传统（右侧面板）/ 清新（视口右缘浮标），默认传统。
- **浮标即列表**：平时只露一列短横线，一条横线对应一个标题，长度与深浅表示层级；鼠标掠过整列横向放大展开成条目，展开只是把每行左侧的文字让出来，不是另开一块面板。
- **滚动联动**：内容滚到哪个标题，大纲就选中哪一条。

## 编辑区右键菜单扩到代码页与富文本页

- **代码页**：刷新 / 全屏 / 专注模式 / 搜索代码（Ctrl+F）/ 复制代码（Ctrl+C）/ 粘贴代码（Ctrl+V）。复制的口径是「有选区复制选区、无选区复制全文」；粘贴走编辑器单事务，Ctrl+Z 一步整体撤回。右键落在既有选区内不会塌缩选区。
- **富文本 `.mh` 页**：刷新 / 全屏 / 专注模式。Markdown 源码语义的表格、标题、格式项对它无意义，故不给。
- **Markdown 页**：v0.5.8 那套表格二级飞窗、标题飞窗与常用格式项保持不变。
- 隐藏工作区后左缘不再保留那条拖动竖线（仍可从标签栏最左端拖出，或点顶栏按钮展开）。

## 修复

- **页面全屏后的行号**：进全屏时行号拉不到贴边、退全屏后被裁掉看不见。根因是重测只盯着不会变形的根盒子，而全屏本质是给编辑器挂一个定位类；现把量测目标换到真正改变形状的滚动区与编辑器盒，并补上类名变化与尺寸结算两条兜底通路。
- **`.mh` 阅读态的右侧大纲一直是空的**：大纲数据从未接到应用状态层（只有 Markdown 引擎绑了上报），现补齐上报与按当前标签的补发。
- **暗色下浮层文字对比不足**：预览浮层里的次要文字原本只有 3.2:1，现已随设计变量补齐一并修掉。

## 界面一致性与无障碍

- **浮层菜单归一**：标签栏、文件树、编辑区、设置等六处右键菜单统一到同一套规格，不再各写各的。
- **图标按钮有名字**：仅靠图标表意的按钮补齐无障碍名称，读屏与键盘用户不再听到一串「按钮」。
- **对话框行为补齐**：Esc 关闭、焦点归还、标题与控件的关联关系一并补上。
- **设计变量补齐**：清掉若干只写在兜底值里、从未落到定义层的变量；新增守卫脚本核对。
