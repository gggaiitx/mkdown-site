# 码克 v0.6.3

这一版集中在预览这一侧：SVG 能格式化了，SVG / 图片预览的自适应与缩放重做了一遍，预览窗格接进了应用右键菜单，并且顺手把码克往「图片查看器」的方向推了一步。

## 新：SVG 源码格式化

- SVG 源码右键菜单与 `Ctrl+Shift+F` 现在会做保守美化：整体重缩进、丢掉元素之间的纯空白、把只含文本的元素收成一行。
- 零依赖自研解析器（`src/utils/markup.ts`），**刻意保守**：混合内容（文本与子元素并存）与没写结束标签的片段一律原样保留，绝不替源码凭空补 `</p>` 这类标签——那里插换行会改变渲染结果。
- 幂等：对已格式化的结果再跑一次不会继续变。
- 只给 `.svg`。`.html` 没给这个入口：真实网页几乎全是混合内容，保守规则改不动一个字节，点了只会收到「已是规范格式」，不如不给。

## 新：预览窗格右键菜单

- HTML / SVG 预览区现在右键能弹出应用菜单：**刷新 / 全屏 / 导出为图片**（导出只给 SVG）。
- 预览里的浏览器原生右键菜单（重新加载 / 查看网页源代码 / 图片另存为）已禁掉。两套沙箱走两条通道：SVG 同源，父页直接挂监听；HTML 是 opaque origin，只能靠注入脚本回报。
- 顺带修掉一处菜单不收：右键项点完一律先收菜单。

## 新：SVG 导出为图片

- 右键「导出为图片」按**当前缩放档位**栅格化出 PNG，先自动裁掉四周空白，再按设置留边。
- 留白做成设置项：**设置 → 导出 → 导出图片留白**（0~40px，默认 2）。
- 长边封顶 8192px：Chromium 对超大 canvas 是静默失败（`toBlob` 直接返回 null），高倍档不设限就会导出失败。
- 只给 SVG。HTML 预览跑在 opaque origin 沙箱里，父页取不到它的画面，浏览器也没有拷贝跨源 iframe 像素的接口。

## 改：SVG 预览的自适应与缩放

- **设计尺寸改从源码读**（`viewBox` / `width|height`）。原先是首帧量 DOM，而只有 `viewBox` 的 svg（各家导出工具的默认产物）会被浏览器解成 100% 容器宽 —— 实测 638×560 的视口量出 638×639，等于把一次布局快照当成了设计尺寸，且量一次就冻结。
- 壳里只要知道设计尺寸就恒写显式 px，缩放全靠外层 CSS zoom 乘上去，改档位不再重载文档。
- **「适应窗口」不再是独立的一套渲染分支**，就是把缩放设成按面板算出来的那一档 —— 所以退出适应时天然接在当前比例上，不会跳变。

## 改：缩放口径三处统一（图片 / HTML / SVG）

- 百分比一律**相对设计尺寸 / 图片自然尺寸**：`100%` 就是 1:1，「实际尺寸」按钮从此名副其实（原先 SVG 的 100% 其实是"铺满面板"）。
- 范围统一成 5% ~ 20000%（原先 SVG/HTML 是 30~300、图片是 10~800，同一个读数在三个面板里表示三种尺寸）。
- 步长按比例走：100% 以下 ×1.1 细档，以上 ×1.25 —— 固定 ±5 在这个区间里要按几百次才到头。
- 图片预览默认**居中铺满**：小图也等比放大到长边贴边，不裁切（原先 `max-width/max-height:100%` 只会缩小，64px 的图标在宽面板里就是中间一个小点）。
- 图片预览支持**鼠标滚轮缩放**，从适应窗口滚第一下按当前视觉比例接手，不跳变。

## 修：某些窗口比例下 SVG 预览一直晃屏

- **根因是自适应算法拉了一个反馈环**：适应率四舍五入会进位，画幅比面板宽出 1px → 冒出滚动条 → 面板可用尺寸缩水 → 重算 → 这次算小了 → 滚动条消失 → 尺寸又变大 → 再进位。每 150ms 一轮，就是"一直晃屏"，且只在"哪条边决定适应率"即将翻转的那段尺寸里发作。
- 改成**两处向下取整**（档位值与盒尺寸），实测 501×306 / 501×310 从三个状态来回翻变成单一稳定态。
- 顺带消掉一类隐性症状：奇数面板宽下即使不抖，也会常驻一条 1px 的横向滚动条。

## 改：预览工具条改为 hover 浮出

- 图片 / HTML / SVG 三处共用的那条工具条默认收起，内容占满整块面板，鼠标进面板才从顶缘浮出（三个宿主挂同一个类，收放规则只写一份）。
- 收起只用透明度与位移，不用 `visibility:hidden` —— 那样条上的按钮不可聚焦，键盘 Tab 永远进不去；现在 Tab 落到条上会由 `:focus-within` 顶出来。

## 新：往「图片查看器」推的两步

- **双击图片区域 = 全屏 / 再双击还原**，与工具条按钮、F11 同一份状态。
- 从资源管理器等**外部打开图片时自动进页面全屏**（从目录树或标签里点图片不变，免得在工作区里看一眼图就把壳铺满）。
- **文件关联从 2 组扩到 5 组 / 284 个扩展名**：图片、图形与网页（SVG/HTML）、文档预览（PDF/Word/Excel）、文本与代码。清单直接由 Rust 侧的 `TEXT_EXTS` / `IMAGE_EXTS` 生成，登记的和能打开的是同一份，不再两处手抄。

## 新：Ctrl+Tab 开合工作区侧栏

- 与工具栏那颗侧栏按钮共用同一个函数，并登记进「设置 → 快捷键」。
- Mac 上 `⌘Tab` 被系统截去切换程序，实际只有 `Ctrl` 生效。

## 已知限制

- **文件关联要装 NSIS 安装包才生效**：那是安装期写注册表的东西，绿色版/dev 构建不会注册。
- HTML 预览不能导出图片（沙箱取不到像素）；少数依赖 `localStorage` 的网页在预览里仍会报错，这类页面请用工具条上的「系统打开」在浏览器里看。
- SVG 里引用了外部位图或外链字体时，canvas 会被判脏导致导出失败（同源策略，无法绕过）。
- 图片放大态下滚轮用于缩放而不再滚页，挪视口靠拖拽平移与滚动条。
- `.html` 源码不提供格式化入口（原因见上）。
- macOS 产物仍未做代码签名与公证，首次打开需右键「打开」绕过 Gatekeeper。
- 本版全部改动只过了无头探针与本机自测（含用真实架构图 SVG 跑通导出链路），未逐项人工回归。
