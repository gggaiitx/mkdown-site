# 码克 v0.7.7

这一版只做一件事：把文件关联收回到 Markdown 本身，并清掉旧版装到注册表里的 200+ 扩展名强绑定。

## 文件关联只保留 .md / .mh

- 0.6.3 至 0.7.6 的安装器把 280+ 个扩展名一并写进了文件关联——其中包含 `.bat`、`.vbs`、`.js`、`.ps1` 这类本应由系统解释执行（cmd / WScript / PowerShell）的脚本类型，导致双击这些文件时被码克接管，批处理不再直接执行。
- 本次安装器只声明 `.md` 与 `.mh` 两个扩展名。`.markdown` / `.mdx` 以及代码、图片、PDF、HTML 等类型不再注册系统关联；应用内打开、拖入、资源管理器「打开方式」均不受影响。
- 已装 0.6.3 及以上版本的用户，升级安装时会自动清理旧版写入的扩展名键与 ProgID，双击 `.bat` / `.cmd` / `.js` / `.vbs` / `.ps1` 等文件恢复系统默认行为。

## 升级清理的判定方式

- 只删除「扩展名键的默认值恰好等于裸扩展名」的项——这是旧版安装器的专有写法；系统默认关联（batfile / txtfile / JSFile 等）与 WPS 等其它软件写入的关联不会被触碰。
- 可执行脚本类型同时复位「打开方式」里残留的码克选择，避免出现指向已删除 ProgID 的空关联。

## 已知限制

- 仅清理当前用户（HKCU）关联；历史版本从未写入 HKLM，无需处理。
- 若曾手动在「打开方式」里把某类型指定给码克，升级后可能需要重新选择一次默认程序。
