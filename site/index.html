Core Features

专注写作的每一处细节

从编辑器内核到文件管理，码克围绕本地文档工作流设计了一系列实用能力。

实时预览三模式

编辑、分屏、阅读三种模式一键切换，左侧书写、右侧即时渲染，位置精确同步、所见即所得。

多工作区管理

支持多目录工作区与最近列表，一键切换项目；重启自动恢复上次的标签页与阅读位置。

富媒体应用内预览

Word、Excel、图片、HTML 等格式无需离开应用即可预览，零额外 IO 开销。

图表与公式渲染

内置 Mermaid 流程图与 KaTeX 数学公式支持，技术文档与论文写作得心应手。

本地优先 · 隐私安全

基于 Tauri 的本地应用，所有文档与图片均存储于本机，不上传任何云端。

粘贴即落盘

复制粘贴的图片自动存入 ./assets/ 相对目录并入库，链接永不丢失。

代码编辑引擎

非 Markdown 文本由自建 CodeMirror 6 引擎接管，250+ 语言语法高亮、按需懒加载，源码类文件拖入即开。

纯文本零误渲染

txt / log / csv / tsv 及无扩展名文本按纯文本编辑，#、**、- 等字符保持字面量，不再被误判为 Markdown。

全局搜索

跨工作区文件名与正文检索，支持正则、大小写与仅 Markdown 过滤，结果高亮、点击直达。

FAQ

常见问题

关于本地优先、平台支持与使用的常见疑问，这里都有答案。

文档会上传到云端吗？

不会。码克是纯本地优先应用——文档、图片与配置全部落在本机磁盘，不上云、不登录、不联网。所有文件 IO 都经本地 Rust 命令完成，你的内容始终留在自己电脑上。

支持哪些操作系统？

Windows：NSIS 安装包（x64），自带卸载程序、注册到系统「应用与功能」，卸载保留用户数据。macOS：提供 Apple 芯片（aarch64）与 Intel（x86_64）双架构 dmg。

macOS 打开提示「无法验证开发者 / 已损坏」怎么办？

本应用未做 Apple 开发者签名，首次打开任选其一绕过（只需一次）：① 打开 系统设置 → 隐私与安全性，拉到最底部点击「仍要打开」；② 终端执行 xattr -cr /Applications/码克.app 后正常打开。M 系列芯片选「Apple 芯片版」，Intel 选「Intel 版」。

Markdown 之外的文件能打开吗？

能。代码类 250+ 扩展名语法高亮（py / rs / ts / js / json / sql / css / go / sh / toml / yaml 等）；txt / log / csv / tsv 按纯文本编辑；docx / xlsx / 图片应用内预览；pdf / ppt 等交系统默认程序打开。

大文件能处理吗？

文本类文件以 8MB 为性能闸门——超过则判为不可编辑，避免卡顿。常规文档、笔记与源码远在此阈值内；超大日志 / 数据文件建议用专业编辑器处理。

如何更新到新版本？

应用内「关于」页或顶栏按钮均可手动检查更新；macOS 按当前架构下载 dmg 并替换，Windows 走安装包。发现新版可直接前往发布页获取。

为什么基于 Tauri 而不是 Electron？

Tauri 以原生 WebView（Windows 的 WebView2 / macOS 的 WKWebView）承载界面、Rust 编写后端，安装包体积更小、内存占用更低、启动更快，且天然适配系统安全模型。

支持导出吗？

支持。可导出 HTML（相对路径自动还原），亦可走 WebView 打印为 PDF，满足文档分发与归档需求。
